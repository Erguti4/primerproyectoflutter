CÓDIGO VIVO

El Origen: Función Main

void main() {
  // Aquí inicia la ejecución de la app
  print('Hola Mundo desde Soltel');
}

Estructura Inicial

  • void: Indica que la función no retorna ningún valor.
  • main(): Es el punto de acceso obligatorio para el compilador.
  • print(): Muestra cadenas de texto en la consola de depuración.

Variables y Tipos de Datos

String empresa = 'Soltel';
int empleados = 200;
double version = 3.5;
bool esMultiplataforma = true;

// Inferencia automática de tipos
var proyecto = 'Flutter App';

Tipado Fuerte

  • Tipos explícitos: String, int, double y bool.
  • Uso de var: Dart deduce el tipo automáticamente en la asignación inicial y lo mantiene fijo.

Interpolación de Strings

void main() {
  String tecnologia = 'Dart';
  int nivel = 1;

  // Inserción directa de variables
  print('Curso de $tecnologia - Nivel $nivel');

  // Evaluación de expresiones complejas
  print('Siguiente nivel: ${nivel + 1}');
}

Formateo Eficiente

  • El símbolo $ incrusta variables directamente sin usar concatenaciones complejas (+).
  • Las llaves ${} evalúan operaciones aritméticas o métodos dentro del propio texto.

Control de Nulos (Null Safety)

String nombre = 'Carlos'; // No puede ser null

String? apellido; // Puede almacenar un valor o null

void main() {
  apellido = 'Pérez';
  // Operador de respaldo si es nulo
  String datos = apellido ?? 'Sin apellido';
}

Código Seguro

  • Por defecto, los valores no aceptan valores nulos.
  • El operador ? declara explícitamente una variable opcional.
  • El operador ?? define un valor alternativo de respaldo en caso de nulidad.

Colecciones: Lists y Maps

// Listas estructuradas (Arreglos)
List<String> lenguajes = ['Dart', 'Kotlin', 'Swift'];

// Mapas estructurados (Diccionarios Clave/Valor)
Map<String, dynamic> configuracion = {
  'puerto': 8080,
  'ssl': true,
  'nombre': 'Servidor Producción'
};

Colecciones

  • List maneja colecciones ordenadas mediante índices numéricos.
  • Map vincula claves únicas con valores de cualquier tipo utilizando la palabra clave dynamic.

Condicionales y Bucles

if (empleados > 100) {
  print('Gran empresa');
} else {
  print('Empresa en crecimiento');
}

// Bucle optimizado para colecciones
for (var lenguaje in lenguajes) {
  print('Framework compatible con: $lenguaje');
}

Lógica de Control

  • Estructuras estándar if / else para la toma de decisiones básicas basadas en booleanos.
  • Bucle for...in para recorrer elementos secuenciales en listas de forma simplificada y limpia.

Funciones y Parámetros

// Parámetros nombrados obligatorios y opcionales
void crearUsuario({
  required String login,
  String rol = 'Invitado'
}) {
  print('Usuario: $login con rol: $rol');
}

void main() {
  crearUsuario(login: 'soltel_dev');
}

Sintaxis Flexible

  • Las llaves {} definen parámetros nombrados, evitando errores en el orden de los argumentos.
  • required: Fuerza el envío del parámetro en la llamada.
  • Soporta asignación directa de valores por defecto (= 'Invitado').

Clases y Constructores

class Colaborador {
  String nombre;
  String area;

  // Constructor simplificado de Dart
  Colaborador(this.nombre, this.area);
}

void main() {
  var dev = Colaborador('Ana', 'Mobile');
  print(dev.nombre);
}

Objetos y Clases

  • Las propiedades se declaran definiendo su tipo explícito.
  • El constructor usa la sintaxis abreviada this.propiedad para asignar variables directamente al instanciar, eliminando código repetitivo.

Asincronía: Async / Await

Future<String> consultarApi() async {
  await Future.delayed(Duration(seconds: 3));
  return 'Respuesta de datos';
}

void main() async {
  print('Solicitando...');
  String resultado = await consultarApi();
  print(resultado);
}

Tareas Asíncronas

  • Future<T>: Representa un valor que estará disponible en el futuro.
  • async: Convierte un método en asíncrono.
  • await: Pausa la ejecución de esa función de manera estructurada hasta que se resuelva la petición.
