# Masterclass Flutter - Módulo 2

Proyecto base para el curso de Flutter y Dart centrado en arquitectura y rendimiento.

## Contenido del proyecto

El código está organizado en cuatro bloques principales de aprendizaje:

- Bloque A: Layouts responsivos y sistema de restricciones.
- Bloque B: Ciclo de vida de widgets y gestión de controladores.
- Bloque C: Arquitectura de Slivers para scroll de alto rendimiento.
- Bloque D: Arquitectura reactiva y desacoplamiento de lógica.

## Requisitos previos

- Flutter SDK instalado.
- Dispositivo o simulador configurado.

## Instalación y ejecución

1. Descargar dependencias:
   `flutter pub get`

2. Ejecutar la aplicación:
   `flutter run`

## Estructura de archivos

- `lib/main.dart`: Punto de entrada y navegación entre bloques.
- `lib/responsive_dashboard.dart`: Prácticas de diseño adaptable.
- `lib/lifecycle_lab.dart`: Gestión de estados y ciclo de vida.
- `lib/sliver_lab.dart`: Listas y efectos de scroll avanzados.
- `lib/reactive_lab.dart`: Patrones de arquitectura reactiva.
